# 多说话人属性识别能力：说话人画像识别（年龄/性别/情感/口音可选｜单选题｜<spk_a>/<spk_b>）
你是 QA 构造专家。输入为多说话人转录与对应音频（含 spk_id、transcript，可能含 start_time/end_time/seg_id，且你可以听音频），并可能包含说话人/片段级属性标注字段：age、gender、emotion、accent（字段名可能略有差异，但语义一致）。
目标：构造四选一单选题，评估 LALM 的“说话人画像识别”能力：性别、年龄段、情感（口音可选）。

================================================
【重要总原则】
- 画像题的“ground truth”必须来自输入给定的属性标注字段（age/gender/emotion/accent）。不得凭文本语义、剧情常识或主观臆测编造正确答案。
- 你可以听音频来挑选“更清晰、单人、可定位”的片段用于出题，但答案字段取值必须与输入标注一致。
- 不使用 turn/轮次/turn_index 定位。
- 题干可用时间或文本片段定位（视模板而定）；选项中不要出现 seg_id / spk_id。
- no_index：评测侧会把目标说话人片段裁剪后提供给模型，因此题干不得出现时间与 transcript 内容，只描述“单人讲话音频”。

================================================
【spk_index 定义（必须严格遵守）】
- spk_index 是“全局说话人顺序编号”，基于整段输入转录中 spk_id 的首次出现顺序确定：
  - 第一个首次出现的 spk_id => spk_1
  - 第二个首次出现的 spk_id => spk_2
  - 以此类推
- spk_index 仅用于 reverse_* 两类题目的答案与选项展示，以及 speaker_meta 字段记录；
  除 reverse_* 外，题干/选项/答案中不得使用 spk_1/spk_2/...（只能用 <spk_a>/<spk_b>）。

================================================
【说话人代号选择与替换（先选一次，全题复用｜强制执行）】
在生成任何题目之前，你必须先从输入转录中挑选“两个不同说话人”的代表性单句片段（segment），并在后续所有题目中复用同一对片段：
- 片段 A：来自说话人 spk_id_A，且该片段的画像字段可用（至少 age/gender/emotion 三项均非缺失/unknown/null）
- 片段 B：来自另一说话人 spk_id_B（spk_id_B ≠ spk_id_A），且其画像字段同样可用（至少 age/gender/emotion 三项均非缺失/unknown/null）
- 为保证问题质量，片段A和片段B都不能是本段语音中第一句话

强制要求（用于保证可评测性与干扰项可构造）：
- <spk_a> 与 <spk_b> 的“画像三项（age/gender/emotion）组合”必须不完全相同（至少一项不同），否则无法构造 wrong speaker 且可能出现多解 => 输出 []。
- 两个片段都必须能“唯一定位”到输入（通过 seg_id 或 start/end 或 transcript 组合能定位），否则输出 []。
- 每个片段尽量单说话人主导，transcript 不要过短。

代号规则：
- 片段 A 对应说话人代号为 spk_a，片段 B 对应说话人代号为 spk_b
- 在题干/选项/答案文本中，凡出现说话人指代，必须使用尖括号包裹的代号：<spk_a>、<spk_b>
- 严禁出现原始 spk_id、以及“第k个说话人”等顺序称呼（除 reverse_* 题用 spk_1/spk_2/... 外）
- 这两个片段必须在输出中的 speaker_meta 里单独给出（数组第 1 个元素），供后处理替换或裁剪音频使用

================================================
【画像字段与是否包含口音（必须一致）】
画像字段默认包含三项：性别 gender + 年龄 age + 情感 emotion。
口音 accent 为可选项：只有当满足以下条件时，才允许把口音纳入画像（并要求 A/B/C 三个画像选项都同时包含口音字段）：
- <spk_a> 与 <spk_b> 的 accent 均非缺失/unknown/null，且你认为该口音在音频上“明显可辨/高置信”（或输入标注明确可靠）；
否则视为“口音不纳入画像”，则本题的 A/B/C 三个画像选项中都不得出现口音字段，hallucination 也不得凭空添加口音字段。

一致性规则（强制）：
- 若本题纳入口音：A/B/C 三个画像选项都必须包含 4 项：性别+年龄+情感+口音
- 若本题不纳入口音：A/B/C 三个画像选项都只能包含 3 项：性别+年龄+情感（完全不出现口音）

================================================
【最终输出格式（严格 JSON｜speaker_meta 单独输出一次）】
输出为一个 JSON 数组，结构固定为：
- 第 1 个元素：只包含 speaker_meta（spk_a 与 spk_b 的单句片段信息）
- 后续元素：每个元素是一道选择题对象
若无法生成任何一道题（任一模板都不满足）=> 直接输出 []（不要只输出 speaker_meta）。

[
  {
    "speaker_meta":{
      "spk_a": [{"seg_id": "...", "start_time": xxx, "end_time": xxx, "transcript": "...", "spk_id": "...", "spk_index": "spk_1", "age": "...|unknown|null", "gender": "...|unknown|null", "emotion": "...|unknown|null", "accent": "...|unknown|null"}],
      "spk_b": [{"seg_id": "...", "start_time": xxx, "end_time": xxx, "transcript": "...", "spk_id": "...", "spk_index": "spk_2", "age": "...|unknown|null", "gender": "...|unknown|null", "emotion": "...|unknown|null", "accent": "...|unknown|null"}]
    }
  },
  {
    "question": "...",
    "question_type": "no_index|time_index|transcript_index|complex_index|reverse_retrival|reverse_count",
    "options": ["A. ...","B. ...","C. ...","D. ..."],
    "answer": "A",
    "answer_text": "...",
    "rationale": ["A. ground truth","B. wrong speaker","C. hallucination","D. unknown"]
  }
]

字段硬约束：
- speaker_meta 的 seg_id/start_time/end_time/transcript 必须对应你挑选的“同一对片段”，全题复用，不得随题变化。
- 若输入缺少某字段：start_time/end_time/seg_id/age/gender/emotion/accent 可填 null 或 "unknown"；
  但 spk_a 与 spk_b 的 age/gender/emotion 必须可用，否则输出 []。
- options 必须为 4 个且顺序打乱；answer 必须指向 ground truth；answer_text 不含字母前缀。
- rationale 与 A-D 一一对应，含义固定：
  - ground truth：正确画像 / 正确集合 / 正确计数
  - wrong speaker：把画像/集合成员错归因到错误说话人（或由错误归因导致的错误集合/错误计数）
  - hallucination：选项包含对话中不存在的画像组合/说话人/集合（或明显凭空编造）
  - unknown：无法判断（信息不足以确定）
- 只有 reverse_* 模板允许在选项/答案中出现 spk_1/spk_2/...；其余模板一律只能用 <spk_a>/<spk_b> 指代说话人。

================================================
【画像选项文本格式（必须统一）】
若不纳入口音（3项）：
“性别：X；年龄：Y；情感：Z”
若纳入口音（4项）：
“性别：X；年龄：Y；情感：Z；口音：K”
其中 X/Y/Z/K 的取值必须与输入标注字段字符串保持一致（大小写/中文英文一致），不得私自改写同义词导致多解。

unknown 选项固定为：
“无法判断（信息不足以确定）”
unknown 选项不包含任何字段。

================================================
【通用选项构造规则（所有模板适用｜4选1）】
每道题必须构造：1 真 + 1 错归因 + 1 虚构 + 1 不确定，且四项互不相同：
- ground truth：使用题干目标对象（默认 <spk_a>）对应片段的画像（按是否纳入口音规则输出 3 或 4 项）
- wrong speaker：直接使用 <spk_b> 对应片段的画像，错误套用到题干对象上（必须与 ground truth 不完全相同）
- hallucination：编造一个“该对话中未出现过的画像组合”
  - 要求该组合在本对话任一已知说话人的任一片段中都不存在（按 3项/4项完全匹配判断“不存在”）
  - 若无法保证“不存在”（例如标注过于稀疏、你无法核对），则该题不生成
- unknown：固定 “无法判断（信息不足以确定）”

================================================
模板1｜no_index（无索引｜单选｜题干不含时间与转录）
question_type = "no_index"
题干（固定风格）：
“下面单人讲话音频中，说话人的说话人画像最接近以下哪一项？”
条件：
- 评测侧仅提供 <spk_a> 的片段音频；题干不得出现时间与 transcript。
- 必须可构造 wrong speaker 与 hallucination，且四个选项互不相同。

================================================
模板2｜time_index（时间索引｜单选｜用时间定位，不给转录）
question_type = "time_index"
题干格式：
“音频中在第 start 秒到第 end 秒的说话人的说话人画像最接近以下哪一项？”
条件：
- start/end 必须来自 speaker_meta 中 <spk_a> 的同一片段。
- 题干不提供 transcript 文本证据。

================================================
模板3｜transcript_index（转录索引｜单选｜用文本定位，不给时间）
question_type = "transcript_index"
题干格式：
“音频中说过‘content’的说话人的说话人画像最接近以下哪一项？”
条件：
- content 必须来自 speaker_meta 中 <spk_a> 的 transcript（可截取连续子串，但必须能在全对话中唯一定位该片段，避免多人重复短句）。
- 题干不出现时间。

================================================
模板4｜speaker_index（按全局说话人顺序索引问性别｜单选）
question_type = "speaker_index"

题干格式（按你想要的风格）：
“在整段对话中，第 x 个出现的说话人的性别是什么？”

其中：
- x 必须严格对应 spk_index = spk_x（由 spk_id 首次出现顺序确定）。
- 本模板题干中不得出现 <spk_a>/<spk_b>，也不得出现原始 spk_id。

x 的选择策略（建议强制，保证可出题且干扰项可构造）：
- 优先令 spk_x = speaker_meta.spk_a[0].spk_index 或 speaker_meta.spk_b[0].spk_index；
  这样你可以用“另一位 speaker_meta 里的说话人”的性别作为 wrong speaker（且两人性别已被你前面的选段约束保证不同）。

生成条件（必须全部满足）：
- 目标 spk_x 的 gender 标注必须可用（非缺失/unknown/null）。
- 若无法保证唯一正确（例如找不到该 spk_x 的标注、或选项无法互异）=> 不生成该题。

================================================
模板5｜complex_index（复杂索引｜单选｜时间+转录联合定位，不给任何画像先验）
question_type = "complex_index"
题干格式（只允许时间+内容定位）：
“在第 start 秒到第 end 秒说过‘content’的说话人，其说话人画像最接近以下哪一项？”
条件：
- start/end/content 必须同时来自 speaker_meta 中 <spk_a> 的同一片段（同一 seg_id）。
- 题干不得泄露任何画像字段（不得出现“男性/女性/成年/愤怒/某口音”等提示）。

================================================
模板6｜reverse_retrival（反向检索｜单选｜问全局哪些 spk_index 满足画像条件 P）
question_type = "reverse_retrival"
题干格式：
“在整段音频中，说话人画像为 P 的说话人有哪些？（用 spk_index 作答）请选择最符合的一项。”
其中画像条件 P 的构造规则：
- 默认取 <spk_a> 的画像作为 P（按本题是否纳入口音决定 3项或4项），例如：
  - 不纳入口音：P = “性别：X；年龄：Y”
  - 纳入口音：P = “性别：X；年龄：Y；口音：K”
集合定义：
- S = {spk_k | 该说话人在任一可用片段中出现过画像 == P（按 3项/4项完全一致匹配）}
唯一性要求：
- 为避免歧义：参与判定的说话人必须在对应字段上“可用且一致”，若存在缺失/unknown 导致无法排除某人是否属于 S，则跳过该题。
选项构造（必须 1真 + 1遗漏/错归因 + 1虚构 + 1不确定；顺序打乱）：
- ground truth：列出 S（示例：spk_1、spk_3；按编号升序）
- wrong speaker：从 S 中去掉 1 人，或把其中 1 人替换为另一个真实存在但不属于 S 的 spk_k
- hallucination：在 S 基础上额外加入 ≥1 个不属于 S 的 spk_k（可加入不存在的 spk_99）
- unknown：无法判断（信息不足以确定）

================================================
模板7｜reverse_count（反向计数｜单选｜问全局满足画像条件 P 的说话人有几个）
question_type = "reverse_count"
题干格式：
“在整段音频中，说话人画像为 P 的说话人一共有几个？请选择最符合的一项。”
其中 P 与 reverse_retrival 一致；集合 S 与唯一性前提同上。
令 count = |S|。
选项构造（顺序打乱）：
- ground truth：count（建议写成“count 个”）
- wrong speaker：由错误归因导致的错误计数（例如 count-1 或 count+1，需与一个合理的“遗漏/错加”一致）
- hallucination：明显不可能或与说话人数量矛盾的计数（例如 99 个）
- unknown：无法判断（信息不足以确定）

================================================
【全局失败条件（任一触发直接输出 []）】
- 无法选出两位不同说话人固定片段（spk_a/spk_b），或任一人的 age/gender/emotion 缺失/unknown/null
- spk_a 与 spk_b 的画像三项组合完全相同（无法构造 wrong speaker 且可能多解）
- 任一道题无法做到四个 options 互不相同
- reverse_* 模板中集合/计数无法唯一确定（存在缺失/冲突导致歧义）

开始生成：请仅输出符合格式的 JSON；若无法满足约束则输出 []。
