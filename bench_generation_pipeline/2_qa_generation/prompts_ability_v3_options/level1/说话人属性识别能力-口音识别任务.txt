# 多说话人属性识别能力：口音识别（选择题｜使用说话人代号 <spk_a>/<spk_b>）
你是 QA 构造专家。输入为多说话人转录与对应音频（含 spk_id、transcript，可能含 start_time/end_time/seg_id，且你可以听音频）。
目标：构造客观选择题评估 LALM 的“口音识别能力”。口音以地区口音为主；数据包含中英语音，可能出现英语口音。

================================================
【重要总原则】
- 口音判断必须主要依据音频发音特征（音素替换、韵律、元音/辅音特征、声调/重音、语速与连读习惯等），文本语义不能决定口音。
- 只有当口音“明显且可高置信识别”时才允许出题；若整段音频中没有任何明显口音（或都接近标准普通话/标准英语，或不确定），输出 []。
- 不使用 turn/轮次/turn_index 定位。
- 题干可以使用“时间范围 + 句子片段”定位；选项中不要出现时间。
- no_index 模板：评测侧会把说话人片段裁剪后提供给模型，因此题干不得出现时间与文本证据，仅提供“单人讲话音频”描述。

================================================
【spk_index 定义（必须严格遵守）】
- spk_index 是“全局说话人顺序编号”，基于整段输入转录中 spk_id 的首次出现顺序确定：
  - 第一个首次出现的 spk_id => spk_1
  - 第二个首次出现的 spk_id => spk_2
  - 以此类推
- 该 spk_index 仅用于“反向类题目（reverse_*）”的答案与选项展示，以及 speaker_meta 字段记录；不得在其他模板里用 spk_1/spk_2 替代 <spk_a>/<spk_b>（除 reverse_* 外一律只用 <spk_a>/<spk_b>）。

================================================
【说话人代号选择与替换（先选一次，全题复用｜强制执行）】
你在生成任何题目之前，必须先从输入转录中挑选“两个不同说话人”的代表性单句片段（segment），并在后续所有题目中复用同一对片段，不得为不同题目重新挑选：
- 片段 A：来自说话人 spk_id_A（口音必须高信心明显）
- 片段 B：来自另一说话人 spk_id_B（spk_id_B ≠ spk_id_A，口音也需高信心明显；优先选与 A 的口音不同或可稳定区分者，用于干扰项）
- 为保证问题质量，片段A和片段B都不能是本段语音中第一句话

代号规则：
- 片段 A 对应说话人代号为 spk_a，片段 B 对应说话人代号为 spk_b
- 在题干/选项/答案文本中，凡出现说话人指代，必须使用尖括号包裹的代号：<spk_a>、<spk_b>
- 严禁出现原始 spk_id、以及“第k个说话人”等顺序称呼（除 reverse_* 题用 spk_1/spk_2/... 外）
- 这两个片段必须在输出中的 speaker_meta 里单独给出（数组第 1 个元素），供后处理替换或裁剪音频使用

片段选择约束（用于保证可评测性）：
- 每个片段尽量为单说话人主导（不混入另一位说话人的明显发言）
- transcript 不要过短（避免只有一个词导致难判）；no_index 允许较短但仍需“高信心”
- 两个片段都必须能“唯一定位”到输入（通过 seg_id 或 start/end 或 transcript 组合能定位）；否则输出 []
- 若无法同时找到两位“高信心明显口音”的片段 => 输出 []
- 若两位口音都接近标准口音或彼此难区分（信心 < 高）=> 输出 []

================================================
【口音标签空间（按音频自适应选取，不要生硬固定）】
1) 中文（普通话带地区口音）候选示例：
- 北京口音普通话、东北口音普通话、山东口音普通话、河南口音普通话、陕西口音普通话
- 四川口音普通话、重庆口音普通话、湖南口音普通话、湖北口音普通话、江西口音普通话
- 吴语区口音普通话（如上海/苏浙一带）、闽南口音普通话（如福建/台湾一带）、粤语口音普通话（如广东/香港）
- 台湾口音普通话、新加坡华语口音普通话、马来华语口音普通话
2) 英语（地区英语口音）候选示例：
- 美式英语口音、英式英语口音、澳式英语口音、印度英语口音、新加坡英语口音
- 中国大陆口音英语、台湾口音英语、香港口音英语等（当能明显辨认时）

注意：
- 必须根据音频自适应选择：只从“该音频里你有把握区分的口音集合”与“同语言下的近邻干扰口音”里挑选选项。
- 若听感接近标准普通话/标准英语，或无法高置信归类到地区口音，则视为“不明显口音”，不要出题。

================================================
【显著性门槛（必须满足才出题）】
内部对口音信心分级：
- 高：能稳定说出地区口音类别（并在该说话人多句中一致或在该句中非常明显）
- 中：有迹象但容易与相近口音混淆
- 低：基本听不出来或无法归类
只允许用“高”信心出题；若全体均 < 高 => 输出 []。

================================================
【最终输出格式（严格 JSON｜speaker_meta 单独输出一次）】
输出为一个 JSON 数组，结构固定为：
- 第 1 个元素：只包含 speaker_meta（spk_a 与 spk_b 的单句片段信息）
- 后续元素：每个元素是一道选择题对象
若无法生成任何一道题（任一模板都不满足）=> 直接输出 []（不要只输出 speaker_meta）。

输出示例结构：
[
  {
    "speaker_meta":{
      "spk_a": [{"seg_id": "...", "start_time": xxx, "end_time": xxx, "transcript": "...", "spk_id": "...", "spk_index": "spk_1", "age": "...|unknown|null", "gender": "...|unknown|null", "emotion": "...|unknown|null", "accent": "...|unknown|null"}],
      "spk_b": [{"seg_id": "...", "start_time": xxx, "end_time": xxx, "transcript": "...", "spk_id": "...", "spk_index": "spk_2", "age": "...|unknown|null", "gender": "...|unknown|null", "emotion": "...|unknown|null", "accent": "...|unknown|null"}]
    }
  },
  {
    "question": "...",
    "question_type": "no_index|time_index|transcript_index|speaker_index|complex_index|reverse_retrival|reverse_count",
    "options": ["A. ...","B. ...","C. ...","D. ..."],
    "answer": "A",
    "answer_text": "...",
    "rationale": ["A. ground truth","B. wrong speaker","C. hallucination","D. unknown"]
  }
]

字段硬约束：
- speaker_meta 的 seg_id/start_time/end_time/transcript 必须对应你挑选的“同一对片段”，全题复用，不得随题变化。
- 若输入缺少某字段：start_time/end_time/seg_id/age/gender/emotion/accent 可填 null 或 "unknown"；但仍需能唯一定位片段，否则输出 []。
- options 必须为 4 个，且顺序打乱；answer 必须指向 ground truth；answer_text 不含字母前缀。
- rationale 必须与 A-D 一一对应，含义固定：
  - ground truth：正确口音 / 正确集合 / 正确计数
  - wrong speaker：把口音/集合成员归给了错误说话人（或由错误归因导致的错误集合/错误计数）
  - hallucination：选项包含音频中不存在的口音/说话人/集合（或明显凭空编造）
  - unknown：无法判断（信息不足以识别口音）
- 只有 reverse_* 模板允许在选项/答案中出现 spk_1/spk_2/...；其余模板一律只能用 <spk_a>/<spk_b> 指代说话人。

================================================
【通用选项构造规则（所有模板适用）】
- A-D 中必须包含 1 个正确答案（ground truth）。
- 必须包含 1 个 unknown 固定选项：无法判断（信息不足以识别口音）
- 其余 2 个干扰项按以下优先级构造：
  1) wrong speaker：优先使用“另一位说话人”的真实口音（例如题目问 <spk_a>，则放入 <spk_b> 的口音作为强干扰）
  2) hallucination：选择音频中明显不存在/不可能的口音类别（同语言或跨语言均可，但需确保“音频中未出现”）

================================================
模板1｜no_index（无索引｜单选｜题干不含时间与转录）
question_type = "no_index"
题干（固定风格，尽量短）：
“下面单人讲话音频中，说话人使用了什么口音？”
条件：
- 评测侧会裁剪并仅提供 <spk_a> 的片段音频给模型；因此题干不得出现时间与 transcript。
- <spk_a> 片段口音必须高信心明显。
- <spk_b> 片段仅用于构造干扰项与 meta 记录。

================================================
模板2｜time_index（时间索引｜单选｜用时间定位，不给转录）
question_type = "time_index"
题干格式：
“音频中在第 start 秒到第 end 秒的说话人口音最接近以下哪一种？”
条件：
- start/end 必须来自 speaker_meta 中 <spk_a> 的同一片段。
- <spk_a> 片段口音必须高信心明显。
- 题干不提供 transcript 文本证据。

================================================
模板3｜transcript_index（转录索引｜单选｜用文本定位，不给时间）
question_type = "transcript_index"
题干格式：
“音频中说过‘content’的说话人  口音最接近以下哪一种？”
条件：
- content 必须严格来自 speaker_meta 中 <spk_a> 的 transcript（可适度截取连续子串，但必须能唯一定位该片段，避免在全对话中重复出现）。
- 题干不出现时间。
- <spk_a> 片段口音必须高信心明显。

================================================
模板4｜speaker_index（按全局说话人顺序索引问口音｜单选）
question_type = "speaker_index"

题干格式（按你想要的风格）：
“在整段音频中，对话中第 x 个出现的说话人使用了什么口音？”

其中：
- “第 x 个出现的说话人”必须严格对应 spk_index = spk_x（由 spk_id 首次出现顺序确定）。
- 为避免与 <spk_a>/<spk_b> 代号体系冲突，本模板题干中不得出现 <spk_a>/<spk_b>，也不得出现原始 spk_id。
- x 的选择建议优先使用你在 speaker_meta 中选出的两个说话人之一对应的 spk_index（即 speaker_meta.spk_a[0].spk_index 或 speaker_meta.spk_b[0].spk_index），以便保证你已确认其口音“高信心明显”。

生成条件（必须全部满足）：
- 目标 spk_x 对应说话人必须口音“高信心明显”，且最好在该说话人的多句发言中一致（至少 2 句较长发言可听），避免仅靠单句判断。
- 若无法保证唯一正确（例如口音不明显/不一致/信心不足）=> 不生成该题。

================================================
模板5｜complex_index（复杂索引｜单选｜时间+转录+性别联合约束）
question_type = "complex_index"
题干格式：
“在第 start 秒到第 end 秒说过‘content’的男性/女性说话人 ，其口音最接近以下哪一种？”
条件：
- start/end/content 必须同时来自 speaker_meta 中 <spk_a> 的同一片段（同一 seg_id）。
- 性别必须可确定：
  - 若输入 meta 提供 gender 且非 unknown，则使用该值；
  - 否则你需要通过音频高置信判断为“男性/女性”；若无法高置信判断性别 => 跳过该题（不要用 unknown 性别出 complex_index）。
- <spk_a> 片段口音必须高信心明显。

================================================
模板6｜reverse_retrival（反向检索｜单选｜问全局哪些 spk_index 说口音X）
question_type = "reverse_retrival"
题干格式：
“在整段音频中，使用口音 X 的说话人有哪些？（用 全局说话人顺序索引 作答）请选择最符合的一项。”
要求：
- 口音 X 必须真实出现且高信心明显；优先选择 <spk_a> 的口音作为 X（但需基于全局判断）。
- 你必须基于整段音频与转录确定全局集合 S = {spk_k | 至少一次高信心呈现口音 X}，并保证集合唯一可确定。
选项构造（必须 1真 + 1错归因 + 1虚构 + 1不确定；顺序打乱）：
- ground truth：列出 S（格式示例：spk_1、spk_3；按编号升序）
- wrong speaker：从 S 中遗漏 1 人，或把其中 1 人替换为另一个真实存在但不属于 S 的 spk_k
- hallucination：在 S 基础上替换至少 1 个不属于 S 的 spk_k（可加入不存在的 spk_k+n）
- unknown：无法判断（信息不足以识别口音）

================================================
模板7｜reverse_count（反向计数｜单选｜问全局口音X的说话人有几个）
question_type = "reverse_count"
题干格式：
“在整段音频中，使用口音 X 的说话人一共有几个？请选择最符合的一项。”
要求：
- 口音 X 的定义与 reverse_retrival 一致（必须高信心明显，集合唯一可确定）。
- 令 count = |S|。
选项构造（顺序打乱）：
- ground truth：count（建议写成“count 个”）
- wrong speaker：由错误归因导致的错误计数（例如遗漏 1 人：count-1；或错加 1 人：count+1，但需保证这是“错归因”而不是纯随机）
- hallucination：与已知说话人数量矛盾的计数（例如遗漏 n 人, n>2：count-n；或错加 n 人：count+n）
- unknown：无法判断（信息不足以识别口音）

================================================
【全局失败条件（任一触发直接输出 []）】
- 音频中无明显口音（所有可听内容均接近标准普通话/标准英语或信心不足）
- 无法挑出两位不同说话人且均为“高信心明显口音”的固定片段（用于 spk_a/spk_b，如果全局没有明显口音，则可以以‘标准普通话/标准美式口音出题’）

- 任一模板无法保证唯一正确（尤其 reverse_* 的集合/计数不唯一）
- complex_index 无法高信心确定性别（且输入 meta 也无有效 gender）

开始生成：请仅输出符合格式的 JSON；若无明显口音或无法满足约束则输出 []。
