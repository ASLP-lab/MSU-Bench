# 多说话人属性识别能力：性别识别（选择题｜使用说话人代号 <spk_a>/<spk_b>）
你是 QA 构造专家。输入为多说话人转录与对应音频（含 spk_id、transcript，可能含 start_time/end_time/seg_id，且你可以听音频），并包含说话人性别标注字段 gender/sex（或等价字段）。
目标：构造客观选择题评估 LALM 的“性别识别能力”。

================================================
【重要总原则】
- 正确答案只能来自输入的性别标注字段（gender/sex 等），不得根据措辞/语气/内容语义或主观听感猜测 ground truth。
- 你可以听音频来“挑选更清晰、单人、可定位的片段”用于出题，但答案必须严格取自标注字段。
- 若相关说话人的性别字段缺失/unknown/null，则涉及该说话人的题不生成。
- 不使用 turn/轮次/turn_index 定位。
- 题干可用时间或文本片段定位（视模板而定）；选项中不要出现 seg_id。
- no_index：评测侧会把说话人片段裁剪后提供给模型，因此题干不得出现时间与文本证据，仅描述“单人讲话音频”。

================================================
【标签空间（统一输出中文）】
- 性别取值空间：{男性, 女性}
- unknown 固定选项：无法判断（信息不足以确定性别）
- hallucination 选项必须使用“标注体系不存在”的性别类别，例如：  不确定性别（不得与 ground truth 或 wrong speaker 重复）

================================================
【spk_index 定义（必须严格遵守）】
- spk_index 是“全局说话人顺序编号”，基于整段输入转录中 spk_id 的首次出现顺序确定：
  - 第一个首次出现的 spk_id => spk_1
  - 第二个首次出现的 spk_id => spk_2
  - 以此类推
- spk_index 仅用于 reverse_* 与 speaker_index 两类题目的题干/选项/答案展示，以及 speaker_meta 字段记录；
  除 reverse_* 与 speaker_index 外，题干/选项/答案中不得使用 spk_1/spk_2/...（只能用 <spk_a>/<spk_b>）。


================================================
【说话人代号选择与替换（先选一次，全题复用｜强制执行）】
在生成任何题目之前，你必须先从输入转录中挑选“两个不同说话人”的代表性单句片段（segment），并在后续所有题目中复用同一对片段：
- 片段 A：来自说话人 spk_id_A，且性别字段可用（非缺失/unknown/null）
- 片段 B：来自另一说话人 spk_id_B（spk_id_B ≠ spk_id_A），且性别字段可用
- 为保证问题质量，片段A和片段B都不能是本段语音中第一句话

强制要求：
- 两人的性别尽可能不同（一个男性一个女性），如果全局性别都相同，则选择两个相同性别的不同说话人。
- 两个片段都必须能“唯一定位”到输入（通过 seg_id 或 start/end 或 transcript 组合能定位），否则输出 []。

代号规则：
- 片段 A 对应说话人代号为 spk_a，片段 B 对应说话人代号为 spk_b
- 在题干/选项/答案文本中，凡出现说话人指代，必须使用尖括号包裹的代号：<spk_a>、<spk_b>
- 严禁出现原始 spk_id、以及“第k个说话人”等顺序称呼（除 reverse_* 题用 spk_1/spk_2/... 外）
- 这两个片段必须在输出中的 speaker_meta 里单独给出（数组第 1 个元素），供后处理替换或裁剪音频使用

片段选择建议（不改变 ground truth）：
- 片段尽量为单说话人主导、发音清晰、时长适中，避免仅“嗯/啊/哦”等无意义短音。

================================================
【最终输出格式（严格 JSON｜speaker_meta 单独输出一次）】
输出为一个 JSON 数组，结构固定为：
- 第 1 个元素：只包含 speaker_meta（spk_a 与 spk_b 的单句片段信息）
- 后续元素：每个元素是一道选择题对象
若无法生成任何一道题（任一模板都不满足）=> 直接输出 []（不要只输出 speaker_meta）。

输出示例结构：
[
  {
    "speaker_meta":{
      "spk_a": [{"seg_id": "...", "start_time": xxx, "end_time": xxx, "transcript": "...", "spk_id": "...", "spk_index": "spk_1", "age": "...|unknown|null", "gender": "...|unknown|null", "emotion": "...|unknown|null", "accent": "...|unknown|null"}],
      "spk_b": [{"seg_id": "...", "start_time": xxx, "end_time": xxx, "transcript": "...", "spk_id": "...", "spk_index": "spk_2", "age": "...|unknown|null", "gender": "...|unknown|null", "emotion": "...|unknown|null", "accent": "...|unknown|null"}]
    }
  },
  {
    "question": "...",
    "question_type": "no_index|time_index|transcript_index|speaker_index|complex_index|reverse_retrival|reverse_count",
    "options": ["A. ...","B. ...","C. ...","D. ..."],
    "answer": "A",
    "answer_text": "...",
    "rationale": ["A. ground truth","B. wrong speaker","C. hallucination","D. unknown"]
  }
]

字段硬约束：
- speaker_meta 的 seg_id/start_time/end_time/transcript 必须对应你挑选的“同一对片段”，全题复用，不得随题变化。
- 若输入缺少某字段：start_time/end_time/seg_id/age/emotion/accent 可填 null 或 "unknown"；
  但 spk_a 与 spk_b 的 gender 必须可用且互异，否则输出 []。
- options 必须为 4 个且顺序打乱；answer 必须指向 ground truth；answer_text 不含字母前缀。
- rationale 必须与 A-D 一一对应，含义固定：
  - ground truth：题干对象对应的真实性别（来自标注字段）
  - hallucination：使用不在标注体系中的性别类别（如“不确定性别”，另一个性别等）
  - unknown：固定 “无法判断（信息不足以确定性别）”
- 只有 reverse_* 模板允许在选项/答案中出现 spk_1/spk_2/...；其余模板一律只能用 <spk_a>/<spk_b> 指代说话人。

================================================
【通用选项构造规则（所有模板适用｜4选1）】
对任一道题：
- ground truth：目标说话人的真实性别（来自标注字段）
- hallucination：选择一个“标注体系不存在”的类别（如“不确定性别”或者另一个性别），且不得与前两者重复
- unknown：固定 “无法判断（信息不足以确定性别）”
若无法让 4 个选项互不相同 => 输出 []。

================================================
模板1｜no_index（无索引｜单选｜题干不含时间与转录）
question_type = "no_index"
题干（固定风格）：
“下面单人讲话音频中，说话人的性别是什么？”
条件：
- 评测侧会裁剪并仅提供 <spk_a> 的片段音频给模型；题干不得出现时间与 transcript。
- <spk_a> 与 <spk_b> 性别字段都可用（已由全局选段保证）。

================================================
模板2｜time_index（时间索引｜单选｜用时间定位，不给转录）
question_type = "time_index"
题干格式：
“音频中在第 start 秒到第 end 秒的说话人的性别是什么？”
条件：
- start/end 必须来自 speaker_meta 中 <spk_a> 的同一片段。
- 题干不提供 transcript 文本证据。

================================================
模板3｜transcript_index（转录索引｜单选｜用文本定位，不给时间）
question_type = "transcript_index"
题干格式：
“音频中说过‘content’的说话人的性别是什么？”
条件：
- content 必须严格来自 speaker_meta 中 <spk_a> 的 transcript（可适度截取连续子串，但必须能在全对话中唯一定位该片段，避免重复出现）。
- 题干不出现时间。

================================================
模板4｜speaker_index（按全局说话人顺序索引问性别｜单选）
question_type = "speaker_index"

题干格式（按你想要的风格）：
“在整段对话中，第 x 个出现的说话人（spk_x）的性别是什么？”

其中：
- x 必须严格对应 spk_index = spk_x（由 spk_id 首次出现顺序确定）。
- 本模板题干中不得出现 <spk_a>/<spk_b>，也不得出现原始 spk_id。

x 的选择策略（建议强制，保证可出题且干扰项可构造）：
- 优先令 spk_x = speaker_meta.spk_a[0].spk_index 或 speaker_meta.spk_b[0].spk_index；

生成条件（必须全部满足）：
- 目标 spk_x 的 gender 标注必须可用（非缺失/unknown/null）。
- 若无法保证唯一正确（例如找不到该 spk_x 的标注、或选项无法互异）=> 不生成该题。

================================================
模板5｜complex_index（复杂索引｜单选｜仅给时间+说话内容｜不提供性别先验）
question_type = "complex_index"
题干格式（必须遵守：不出现“男性/女性”字样作为先验）：
“在第 start 秒到第 end 秒说过‘content’的说话人，其性别是什么？”
条件：
- start/end/content 必须同时来自 speaker_meta 中 <spk_a> 的同一片段（同一 seg_id）。
- 注意：题干不得出现任何性别提示词（不得写“男性/女性说话人”），只允许时间与 content 用于定位。

================================================
模板6｜reverse_retrival（反向检索｜单选｜问全局哪些 spk_index 属于性别G）
question_type = "reverse_retrival"
题干格式：
“在整段音频中，性别为 G 的说话人有哪些？（用 spk_index 作答）请选择最符合的一项。”
要求：
- G ∈ {男性, 女性}，且必须能基于标注唯一确定集合。
- 为保证唯一正确：对话中所有“出现过发言的说话人”必须都有可用 gender 标注；若存在任何说话人 gender 缺失/unknown/null => 跳过该题。
- 定义集合 S = {spk_k | 该说话人的 gender == G}，要求 |S| ≥ 1。
选项构造（必须 1真 + 1错归因 + 1虚构 + 1不确定；顺序打乱）：
- ground truth：列出 S（格式示例：spk_1、spk_3；按编号升序）
- wrong speaker：从 S 中遗漏 1 人，或把其中 1 人替换为另一个真实存在但不属于 S 的 spk_k
- hallucination：在 S 基础上替换 ≥1 个不属于 S 的 spk_k（可加入不存在的 spk_k+n）
- unknown：固定 “无法判断（信息不足以确定性别）”

================================================
模板7｜reverse_count（反向计数｜单选｜问全局性别G的说话人有几个）
question_type = "reverse_count"
题干格式：
“在整段音频中，性别为 G 的说话人一共有几个？请选择最符合的一项。”
要求：
- 与 reverse_retrival 同样要求：所有说话人 gender 标注可用，否则跳过。
- 令 S = {spk_k | gender==G}，count = |S|。
选项构造（顺序打乱）：
- ground truth：count（建议写成“count 个”）
- wrong speaker：由错误归因导致的错误计数（例如 count-1 或 count+1）
- hallucination：与说话人数量矛盾的计数（例如 count+n 个, n>=2）
- unknown：固定 “无法判断（信息不足以确定性别）”

================================================
【全局失败条件（任一触发直接输出 []）】
- 无法选出两位不同说话人固定片段（spk_a/spk_b）
- spk_a 或 spk_b 的 gender 缺失/unknown/null


开始生成：请仅输出符合格式的 JSON；若无法满足约束则输出 []。
