# 多说话人属性识别能力：情感识别（选择题｜使用说话人代号 <spk_a>/<spk_b>）
你是 QA 构造专家。输入为多说话人转录与对应音频（含 spk_id、transcript，可能含 start_time/end_time/seg_id，且你可以听音频），并包含片段级情感标注字段 emotion。
目标：构造客观选择题评估 LALM 的“情感识别能力”。

================================================
【重要总原则】
- 正确答案只能依据输入的 emotion 字段（ground truth 严禁用文本语义/常识/剧情推断；也禁止推断情绪原因、强弱、态度等）。
- 你可以听音频来挑选“更清晰、单人、可定位”的片段用于出题，但答案必须严格取自 emotion 字段。
- 不使用 turn/轮次/turn_index 定位。
- no_index：评测侧会把说话人片段裁剪后提供给模型，因此题干不得出现时间与 transcript 内容，仅描述“单人讲话音频”。

================================================
【spk_index 定义（必须严格遵守）】
- spk_index 是“全局说话人顺序编号”，基于整段输入转录中 spk_id 的首次出现顺序确定：
  - 第一个首次出现的 spk_id => spk_1
  - 第二个首次出现的 spk_id => spk_2
  - 以此类推
- spk_index 仅用于 reverse_* 两类题目的答案与选项展示，以及 speaker_meta 字段记录；
  除 reverse_* 外，题干/选项/答案中不得使用 spk_1/spk_2/...（只能用 <spk_a>/<spk_b>）。

================================================
【说话人代号选择与替换（先选一次，全题复用｜强制执行）】
在生成任何题目之前，你必须先从输入转录中挑选“两个不同说话人”的代表性单句片段（segment），并在后续所有题目中复用同一对片段：
- 片段 A：来自说话人 spk_id_A，且该片段 emotion 可用
- 片段 B：来自另一说话人 spk_id_B（spk_id_B ≠ spk_id_A），且该片段 emotion 可用
- 为保证问题质量，片段A和片段B都不能是本段语音中第一句话

强制要求（用于保证可评测性与选项可构造）：
- ，如果全局没有明显情感标签，则以‘中性或无明显情感’为标签构造问题。
- 每个片段尽量为单说话人主导（不混入另一位说话人的明显发言）。
- transcript 不要过短（避免仅语气词/拟声词导致定位与可用性差）。
- 两个片段都必须能“唯一定位”到输入（通过 seg_id 或 start/end 或 transcript 组合能定位）；否则输出 []。

代号规则：
- 片段 A 对应说话人代号为 spk_a，片段 B 对应说话人代号为 spk_b
- 在题干/选项/答案文本中，凡出现说话人指代，必须使用尖括号包裹的代号：<spk_a>、<spk_b>
- 严禁出现原始 spk_id、以及“第k个说话人”等顺序称呼（除 reverse_* 题用 spk_1/spk_2/... 外）
- 这两个片段必须在输出中的 speaker_meta 里单独给出（数组第 1 个元素），供后处理替换或裁剪音频使用

================================================
【情感标签空间（按输入自适应，不要硬编码）】
- 选项中的情感标签文本必须与输入 emotion 字段的原始标签字符串保持一致（大小写/拼写一致）。
- 可用标签集合 E_dialog = {本段对话中所有出现过的 emotion 标签}。
- ground truth 与 wrong speaker 必须来自 E_dialog
- hallucination 必须选择一个“在本段对话中从未出现过”的情感标签 H（H ∉ E_dialog），且 H ≠ G 且 H ≠ W；
  如果你无法找到满足条件的 H（例如对话标签空间过满或不确定），则对应题目不生成（不要勉强凑）。

================================================
【最终输出格式（严格 JSON｜speaker_meta 单独输出一次）】
输出为一个 JSON 数组，结构固定为：
- 第 1 个元素：只包含 speaker_meta（spk_a 与 spk_b 的单句片段信息）
- 后续元素：每个元素是一道选择题对象
若无法生成任何一道题（任一模板都不满足）=> 直接输出 []（不要只输出 speaker_meta）。

[
  {
    "speaker_meta":{
      "spk_a": [{"seg_id": "...", "start_time": xxx, "end_time": xxx, "transcript": "...", "spk_id": "...", "spk_index": "spk_1", "age": "...|unknown|null", "gender": "...|unknown|null", "emotion": "...|unknown|null", "accent": "...|unknown|null"}],
      "spk_b": [{"seg_id": "...", "start_time": xxx, "end_time": xxx, "transcript": "...", "spk_id": "...", "spk_index": "spk_2", "age": "...|unknown|null", "gender": "...|unknown|null", "emotion": "...|unknown|null", "accent": "...|unknown|null"}]
    }
  },
  {
    "question": "...",
    "question_type": "no_index|time_index|transcript_index|complex_index|reverse_retrival|reverse_count",
    "options": ["A. ...","B. ...","C. ...","D. ..."],
    "answer": "A",
    "answer_text": "...",
    "rationale": ["A. ground truth","B. wrong speaker","C. hallucination","D. unknown"]
  }
]

字段硬约束：
- speaker_meta 的 seg_id/start_time/end_time/transcript 必须对应你挑选的“同一对片段”，全题复用，不得随题变化。
- 若输入缺少某字段：start_time/end_time/seg_id/age/gender/accent 可填 null 或 "unknown"；
- options 必须为 4 个且顺序打乱；answer 必须指向 ground truth；answer_text 不含字母前缀。
- rationale 必须与 A-D 一一对应，含义固定：
  - ground truth：题干对象对应的真实 emotion（来自 emotion 字段）
  - hallucination：一个在该对话中从未出现过的 emotion 标签
  - unknown：固定 “无法判断（证据不足以确定情感）”
- 只有 reverse_* 模板允许在选项/答案中出现 spk_1/spk_2/...；其余模板一律只能用 <spk_a>/<spk_b> 指代说话人。

================================================
【通用选项构造规则（所有模板适用｜4选1）】
对任一道题：
- ground truth：G = 题干目标片段（默认 <spk_a>）的 emotion（）
- wrong speaker：W = <spk_b> 片段的 emotion（ 且 W ≠ G）
- hallucination：H = 对话中未出现过的情感标签（H ∉ E_dialog 且 H ≠ G 且 H ≠ W）
- unknown：固定 “无法判断（证据不足以确定情感）”
若无法让 4 个选项互不相同（尤其无法构造 H 或 W），则该题不生成；若所有题都无法生成，则输出 []。

================================================
模板1｜no_index（无索引｜单选｜题干不含时间与转录）
question_type = "no_index"
题干（固定风格，尽量短）：
“下面单人讲话音频中，说话人的情感最接近以下哪一项？”
条件：
- 评测侧会裁剪并仅提供 <spk_a> 的片段音频给模型；题干不得出现时间与 transcript。
- 仍需用 <spk_b> 构造 wrong speaker，并能构造 hallucination H。

================================================
模板2｜time_index（时间索引｜单选｜用时间定位，不给转录）
question_type = "time_index"
题干格式：
“音频中在第 start 秒到第 end 秒讲话的说话人情感最接近以下哪一项？”
条件：
- start/end 必须来自 speaker_meta 中 <spk_a> 的同一片段。
- 题干不提供 transcript 文本证据。
- 必须可构造 W 与 H。

================================================
模板3｜transcript_index（转录索引｜单选｜用文本定位，不给时间）
question_type = "transcript_index"
题干格式：
“音频中说过‘content’的说话人在该句话的情感最接近以下哪一项？”
条件：
- content 必须严格来自 speaker_meta 中 <spk_a> 的 transcript（可截取连续子串，但必须能在全对话中唯一定位该片段，避免重复出现）。
- 题干不出现时间。
- 必须可构造 W 与 H。

================================================
模板4｜complex_index（复杂索引｜单选｜时间+转录联合定位）
question_type = "complex_index"
题干格式：
“在第 start 秒到第 end 秒说过‘content’的说话人，其情感最接近以下哪一项？”
条件：
- start/end/content 必须同时来自 speaker_meta 中 <spk_a> 的同一片段（同一 seg_id）。
- 注意：题干只允许时间 + content 用于定位，不得泄露任何情感标签。
- 必须可构造 W 与 H。

================================================
模板5｜reverse_retrival（反向检索｜单选｜问全局哪些 spk_index 出现过情感E）
question_type = "reverse_retrival"
题干格式：
“在整段音频中，出现过情感 E 的说话人有哪些？（用 全局说话人顺序 作答）请选择最符合的一项。”
要求：
- E 必须来自本对话中出现过的，且集合可唯一确定。
- 为保证唯一正确：所有“出现过发言的说话人”必须至少有一个非缺失的 emotion 标注（允许出现 Neutral/Other，但不得缺失/unknown/null）；若存在缺失导致无法排除某人可能也出现过 E，则跳过该题。
- 定义集合 S = {spk_k | 该说话人至少一个片段 emotion == E}，要求 |S| ≥ 1。
选项构造（必须 1真 + 1错归因 + 1虚构 + 1不确定；顺序打乱）：
- ground truth：列出 S（示例：spk_1、spk_3；按编号升序）
- wrong speaker：从 S 中遗漏 1 人，或把其中 1 人替换为另一个真实存在但不属于 S 的 spk_k
- hallucination：在 S 基础上替换 ≥1 个不属于 S 的 spk_k（ spk_k+1, spk_k+3等）
- unknown：固定 “无法判断（证据不足以确定情感）”

================================================
模板6｜reverse_count（反向计数｜单选｜问全局情感E的说话人有几个）
question_type = "reverse_count"
题干格式：
“在整段音频中，出现过情感 E 的说话人一共有几个？请选择最符合的一项。”
要求：
- 与 reverse_retrival 相同的唯一性前提：所有说话人 emotion 标注不得缺失，否则跳过。
- S = {spk_k | 至少一次 emotion==E}，count = |S|。
选项构造（顺序打乱）：
- ground truth：count（建议写成“count 个”）
- wrong speaker：由错误归因导致的错误计数（例如 count-1 或 count+1）
- hallucination：明显不可能或与说话人数量矛盾的计数（例如 n+1, n+2 个）
- unknown：固定 “无法判断（证据不足以确定情感）”

================================================
【全局失败条件（任一触发直接输出 []）】
- 无法选出两位不同说话人固定片段（spk_a/spk_b）


开始生成：请仅输出符合格式的 JSON；若无法满足约束则输出 []。
