# 多说话人属性识别能力：年龄段识别（选择题｜使用说话人代号 <spk_a>/<spk_b>）
你是 QA 构造专家。输入为多说话人转录与对应音频（含 spk_id、transcript，可能含 start_time/end_time/seg_id，且你可以听音频），并包含说话人年龄段标注字段 age_group。
目标：构造客观选择题评估 LALM 的“年龄段识别能力”。

================================================
【重要总原则】
- 年龄段 ground truth 只能来自输入标注字段 age_group（不得根据措辞、内容语义、或主观臆测生成正确答案）。
- 你可以听音频来“选择合适的出题片段”（例如尽量单人、清晰、可定位），但正确答案必须严格取自 age_group。
- 若整段对话中无法选择出两位不同说话人且二者 age_group 均可用（非缺失/unknown），则输出 []。
- 不使用 turn/轮次/turn_index 定位。
- 题干可以使用时间或文本片段定位（视模板而定）；选项中不要出现 seg_id。
- no_index：评测侧会把说话人片段裁剪后提供给模型，因此题干不得出现时间与文本证据，仅描述“单人讲话音频”。

================================================
【年龄段标签空间（用于选项与答案文本）】
age_group 枚举（选项文本需要给出具体的范围，直接使用如下标准形式）：
- child (age < 12)
- teenager (13 < age < 17)
- young adult (18 < age < 29)
- adult (30 < age < 59)
- senior adult (age > 60)

================================================
【spk_index 定义（必须严格遵守）】
- spk_index 是“全局说话人顺序编号”，基于整段输入转录中 spk_id 的首次出现顺序确定：
  - 第一个首次出现的 spk_id => spk_1
  - 第二个首次出现的 spk_id => spk_2
  - 以此类推
- spk_index 仅用于 reverse_* 与 speaker_index 两类题目的题干/选项/答案展示，以及 speaker_meta 字段记录；
  除 reverse_* 与 speaker_index 外，题干/选项/答案中不得使用 spk_1/spk_2/...（只能用 <spk_a>/<spk_b>）。

================================================
【说话人代号选择与替换（先选一次，全题复用｜强制执行）】
在生成任何题目之前，你必须先从输入转录中挑选“两个不同说话人”的代表性单句片段（segment），并在后续所有题目中复用同一对片段：
- 片段 A：来自说话人 spk_id_A，且其 age_group 可用（非缺失/unknown/null）
- 片段 B：来自另一说话人 spk_id_B（spk_id_B ≠ spk_id_A），且其 age_group 可用
- 为保证问题质量，片段A和片段B都不能是本段语音中第一句话

优先选择：
- 两人的 age_group 不相同（便于构造 wrong speaker 干扰项）；若确实找不到不同年龄段的两人，则使用相同age group构造。

代号规则：
- 片段 A 对应说话人代号为 spk_a，片段 B 对应说话人代号为 spk_b
- 在题干/选项/答案文本中，凡出现说话人指代，必须使用尖括号包裹的代号：<spk_a>、<spk_b>
- 严禁出现原始 spk_id、以及“第k个说话人”等顺序称呼（除 reverse_* 题用 spk_1/spk_2/... 外）
- 这两个片段必须在输出中的 speaker_meta 里单独给出（数组第 1 个元素），供后处理替换或裁剪音频使用

片段选择约束（用于保证可评测性）：
- 每个片段尽量为单说话人主导（不混入另一位说话人的明显发言）
- transcript 不要过短（避免只有一个词导致定位/可用性差）
- 两个片段都必须能“唯一定位”到输入（通过 seg_id 或 start/end 或 transcript 组合能定位）；否则输出 []

================================================
【最终输出格式（严格 JSON｜speaker_meta 单独输出一次）】
输出为一个 JSON 数组，结构固定为：
- 第 1 个元素：只包含 speaker_meta（spk_a 与 spk_b 的单句片段信息）
- 后续元素：每个元素是一道选择题对象
若无法生成任何一道题（任一模板都不满足）=> 直接输出 []（不要只输出 speaker_meta）。

输出示例结构：
[
 {
    "speaker_meta":{
      "spk_a": [{"seg_id": "...", "start_time": xxx, "end_time": xxx, "transcript": "...", "spk_id": "...", "spk_index": "spk_1", "age": "...|unknown|null", "gender": "...|unknown|null", "emotion": "...|unknown|null", "accent": "...|unknown|null"}],
      "spk_b": [{"seg_id": "...", "start_time": xxx, "end_time": xxx, "transcript": "...", "spk_id": "...", "spk_index": "spk_2", "age": "...|unknown|null", "gender": "...|unknown|null", "emotion": "...|unknown|null", "accent": "...|unknown|null"}]
    }
  },
  {
    "question": "...",
    "question_type": "no_index|time_index|transcript_index|speaker_index|complex_index|reverse_retrival|reverse_count",
    "options": ["A. ...","B. ...","C. ...","D. ..."],
    "answer": "A",
    "answer_text": "...",
    "rationale": ["A. ground truth","B. wrong speaker","C. hallucination","D. unknown"]
  }
]

字段硬约束：
- speaker_meta 的 seg_id/start_time/end_time/transcript 必须对应你挑选的“同一对片段”，全题复用，不得随题变化。
- speaker_meta.age 字段用于承载 age_group（即 child/teenager/young adult/adult/senior adult 的其中之一）；若输入字段名为 age_group，请映射填入 age。
- 若输入缺少某字段：start_time/end_time/seg_id/age/gender/emotion/accent 可填 null 或 "unknown"；
  但 spk_a 与 spk_b 的 age 必须可用，否则输出 []。
- options 必须为 4 个且顺序打乱；answer 必须指向 ground truth；answer_text 不含字母前缀。
- rationale 必须与 A-D 一一对应，含义固定：
  - ground truth：正确年龄段 / 正确集合 / 正确计数
  - wrong speaker：把年龄段/集合成员归给了错误说话人（或由错误归因导致的错误集合/错误计数）
  - hallucination：选项包含对话中不存在的年龄段/说话人/集合（或明显凭空编造）
  - unknown：无法判断（信息不足以确定年龄段）
- 只有 reverse_* 模板允许在选项/答案中出现 spk_1/spk_2/...；其余模板一律只能用 <spk_a>/<spk_b> 指代说话人。

================================================
【通用选项构造规则（所有模板适用｜4选1）】
对任一道题：
- 必须包含 1 个正确答案（ground truth）。
- 必须包含 1 个 unknown 固定选项：无法判断（信息不足以确定年龄段）
- 其余 2 个干扰项按以下优先级构造：
  1) wrong speaker：优先使用“另一位说话人”的真实年龄段（例如题目问 <spk_a>，则使用 <spk_b> 的 age 作为强干扰；如果age都相同则忽略此条件）
  2) hallucination：选择一个不等于 ground truth 且不等于 wrong speaker 的年龄段 H；
     优先选择“相邻/易混淆”的年龄段（例如 young adult vs adult）。

================================================
模板1｜no_index（无索引｜单选｜题干不含时间与转录）
question_type = "no_index"
题干（固定风格）：
“下面单人讲话音频中，说话人的年龄段最接近以下哪一项？”
条件：
- 评测侧会裁剪并仅提供 <spk_a> 的片段音频给模型；题干不得出现时间与 transcript。

================================================
模板2｜time_index（时间索引｜单选｜用时间定位，不给转录）
question_type = "time_index"
题干格式：
“音频中在第 start 秒到第 end 秒的说话人 的年龄段最接近以下哪一项？”
条件：
- start/end 必须来自 speaker_meta 中 <spk_a> 的同一片段。

================================================
模板3｜transcript_index（转录索引｜单选｜用文本定位，不给时间）
question_type = "transcript_index"
题干格式：
“音频中说过‘content’的说话人 的年龄段最接近以下哪一项？”
条件：
- content 必须来自 speaker_meta 中 <spk_a> 的 transcript（可截取连续子串，但必须能在全对话中唯一定位该片段，避免重复出现）。
- 题干不出现时间。

================================================
模板4｜speaker_index（按全局说话人顺序索引问年龄段｜单选）
question_type = "speaker_index"

题干格式（按你想要的风格）：
“在整段对话中，第 x 个出现的说话人（spk_x）的年龄段最接近以下哪一项？”

其中：
- x 必须严格对应 spk_index = spk_x（由 spk_id 首次出现顺序确定）。
- 本模板题干中不得出现 <spk_a>/<spk_b>，也不得出现原始 spk_id。
- x 的选择建议优先取 speaker_meta.spk_a[0].spk_index 或 speaker_meta.spk_b[0].spk_index（你已经为这两位说话人准备了可用的 age_group 标签，且满足“片段A/B不为第一句话”的约束）。

生成条件（必须全部满足）：
- 目标 spk_x 的 age_group 必须可用（非缺失/unknown/null）。
- 若无法保证唯一正确（例如该说话人的 age_group 缺失、或 speaker_meta 无法对应到该 spk_x）=> 不生成该题。


================================================
模板5｜complex_index（复杂索引｜单选｜时间+转录+性别联合约束）
question_type = "complex_index"
题干格式：
“在第 start 秒到第 end 秒说过‘content’的男性/女性说话人，其年龄段最接近以下哪一项？”
条件：
- start/end/content 必须同时来自 speaker_meta 中 <spk_a> 的同一片段（同一 seg_id）。
- 性别必须可确定：
  - 若输入 meta 提供 gender 且非 unknown，则直接使用；
  - 否则你需要通过音频高置信判断为“男性/女性”；若无法高置信判断性别 => 跳过该题。

================================================
模板6｜reverse_retrival（反向检索｜单选｜问全局哪些 spk_index 属于年龄段G）
question_type = "reverse_retrival"
题干格式：
“在整段音频中，年龄段为 G 的说话人有哪些？（用 全局说话人顺序 作答）请选择最符合的一项。”
要求：
- 年龄段 G 必须真实出现于至少一位说话人的 age（来自输入标注），且集合唯一可确定（age 缺失/unknown 的说话人不计入）。
- 定义全局集合 S = {spk_k | 该说话人的 age == G}，要求 |S| ≥ 1。
选项构造（必须 1真 + 1错归因 + 1虚构 + 1不确定；顺序打乱）：
- ground truth：列出 S（格式示例：spk_1、spk_3；按编号升序）
- wrong speaker：从 S 中遗漏 1 人，或把其中 1 人替换为另一个真实存在但不属于 S 的 spk_k
- hallucination：在 S 基础上替换 ≥1 个不属于 S 的 spk_k（可加入不存在的 spk_k+n）
- unknown：无法判断（信息不足以确定年龄段）

================================================
模板7｜reverse_count（反向计数｜单选｜问全局年龄段G的说话人有几个）
question_type = "reverse_count"
题干格式：
“在整段音频中，年龄段为 G 的说话人一共有几个？请选择最符合的一项。”
要求：
- 年龄段 G 与 reverse_retrival 中一致（必须可唯一确定集合 S）。
- 令 count = |S|。
选项构造（顺序打乱）：
- ground truth：count（建议写成“count 个”）
- wrong speaker：由错误归因导致的错误计数（例如遗漏 1 人：count-1；或错加 1 人：count+1）
- hallucination：明显不可能或与已知说话人数量矛盾的计数（例如遗漏 n 人, n>2：count-n；或错加 n 人：count+n）
- unknown：无法判断（信息不足以确定年龄段）

================================================
【全局失败条件（任一触发直接输出 []）】
- 无法选出两位不同说话人固定片段（spk_a/spk_b），或任一人的 age 缺失/unknown
- 任一模板无法保证唯一正确（例如 reverse_* 的集合/计数无法唯一确定）
- complex_index 无法高信心确定性别（且输入 meta 也无有效 gender）

开始生成：请仅输出符合格式的 JSON；若无法满足约束则输出 []。
